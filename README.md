# MoviCampus - Frontend

Frontend del proyecto **MoviCampus** (React + Vite, JavaScript). PWA centrada en dispositivos móviles.

## Comandos

```bash
npm install      # instalar dependencias
npm run dev      # servidor de desarrollo (HMR)
npm run build    # build de producción en dist/
npm run preview  # previsualizar el build
npm run lint     # lint (oxlint)
```

## Estructura

```
src/
├── assets/       # imágenes y estáticos
├── components/   # componentes reutilizables
├── pages/        # páginas de la aplicación (Login, ...)
├── routes/       # definición de rutas
├── services/     # estado, usuarios y helpers de datos
├── App.jsx       # raíz de la aplicación
└── main.jsx      # punto de entrada
```
